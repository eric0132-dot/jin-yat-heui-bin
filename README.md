# 今日去邊

香港家庭／單人活動推薦 PWA。可安裝到主畫面，活動資料內建於前端，離線仍可篩選同瀏覽。

## 功能

- 按同行（單人／家庭／情侶／朋友）、活動類型、時長、消費篩選
- **經典推薦**同**小眾活動**兩頁切換；小眾頁靈感空泛、唔綁死地點
- 可多選 **香港 18 區**篩選：選咗先按區分析推薦，並顯示指明地點
- 內建約 100+ 精選活動（四季／節日），可離線使用
- 可於本機新增／刪除自訂活動（localStorage）
- 按香港季節同常見節慶（新年、端午、中秋、聖誕、暑假等）加權推薦
- 隨機推薦、活動詳情
- Service Worker 快取，支援安裝同離線使用

## 開發

```bash
npm install
npm run dev
```

PWA 圖示已在 `public/`。若要重新產生：`npm i -D sharp@^0.35.3 && npm run icons`。

## 建置

```bash
npm run build
npm run preview
```

建置後用支援 PWA 的瀏覽器開啟，即可「加到主畫面」。首次連線後，之後離線亦可使用。
